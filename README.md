# Закрывающий тег

Адаптивная страница-рефлексия о пути обучения: восемь карточек, CSS-фильтры, анимированные лайки и модальное окно сохранения.

## Запуск
Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages (Settings → Pages → Deploy from a branch).

## Изображения
