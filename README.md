# Закрывающий тег

Адаптивная страница-рефлексия о пути обучения: восемь карточек, локальные SVG-иллюстрации, CSS-фильтры, анимированные лайки и модальное окно сохранения.

## Запуск

Откройте `index.html` в браузере. Внешние изображения и сетевые запросы для отображения карточек не нужны.

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и загрузите в него содержимое этой папки.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Нажмите **Save** и дождитесь публикации. GitHub покажет адрес страницы в этом же разделе.
